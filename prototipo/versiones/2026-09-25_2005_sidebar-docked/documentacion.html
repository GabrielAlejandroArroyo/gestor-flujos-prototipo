Propósito

Este prototipo HTML valida el diseño de un gestor de flujos de trabajo antes de implementarlo con Supabase. Separa la definición del flujo (diseñador) de la ejecución (instancias, traza y reporte). El mock sigue vigente; la app Next.js es la fase siguiente.

Menú del mock

  • Diseñador de flujo (BPMN): Start/User/Service Task, Exclusive Gateway, End Event, Sequence Flow y pantallas en User Task.
  • Gestión de actividades: instanciar flujos listos, resolver tareas manuales (Aceptar/Rechazar) y ejecutar automáticas.
  • Reporte: avance, filtros y traza de cada instancia.

Persistencia del mock

Claves localStorage: gestor_flujos_prototipo_v2 (datos) y gestor_flujos_theme_v1 (tema). Ejemplo «Aprobación de gasto» con User Task → Exclusive Gateway.

Procedimiento de versionado del mock

  • Mock editable en prototipo/; snapshots congelados en prototipo/versiones/YYYY-MM-DD_HHmm_etiqueta/.
  • Índice: versiones.html · versiones.md.
  • Antes de cambios grandes: nuevo snapshot + bitácora; regenerar bundle.js / theme-bundle.js con esbuild.
  • SemVer (lib/version.ts) solo aplica con la app Next.js.

Subconjunto BPMN 2.0

  • Start Event — parámetros; salida siempre.
  • User Task — pantalla; salida siempre al gateway.
  • Exclusive Gateway — salidas aceptar y rechazar.
  • Service Task — salida siempre.
  • End Event — sin salidas.

Arquitectura objetivo (implementación futura)

Tres capas; la implementación arranca contra Supabase local (Docker), no contra la nube.

Presentación — Next.js, React 19, App Router, Server Components, Tailwind CSS, responsive, idiomas ES / EN / PT. Pantallas equivalentes al mock (diseñador con pantallas manuales, gestión, reporte).
Negocio (API First) — API Routes de Next.js; reglas en validation y motor del prototipo; validación Zod. Auth productiva por definir (Supabase Auth vs NextAuth/Azure AD — alinear con supabase-hooks.mdc al implementar).
Datos — Postgres vía Supabase CLI (supabase start); schemas flujo y ejecucion; RLS en migraciones; cloud después con el mismo historial.
Mock HTML (actual) → Implementación → Supabase local + migraciones → Supabase Cloud

Migraciones
